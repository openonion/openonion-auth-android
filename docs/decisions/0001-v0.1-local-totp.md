# ADR 0001: v0.1 is local TOTP only

- Status: accepted for developer preview
- Date: 2026-09-01

## Decision

Version 0.1 imports standard TOTP credentials, encrypts them with an
Android-Keystore-backed AES-GCM key, and generates codes offline. It has no
network permission, cloud sync, Agent pairing, credential export, or HOTP.

The release is a developer preview for test credentials. Production use waits
for independent security review, recovery design, device-authentication gating,
and clean-device testing.

## Why

TOTP correctness and local secret handling form one testable trust boundary.
Adding remote Agent access or synchronization would introduce identity,
transport, replay, recovery, and revocation decisions before that boundary has
been validated.
